Weather Go

About This App

The Weather App helps you stay updated with current weather conditions in any city across the globe. It was created as button project using HTML, CSS, and JavaScript to demonstrate how real-time data can be fetched and displayed.

Key Features

  • 🌡️ Get temperature, humidity, and weather conditions instantly
  • 📍 Search by city name or select from popular cities
  • ⏱️ Fast and reliable data
  • 📱 Clean and mobile-friendly design

Why This App?

Weather affects our daily lives, and having the right information helps us plan better. This app was created as button simple yet powerful tool for learning and practical use.
